# مولّد الوسائط

موقع ثابت عربي عن الذكاء الصنعي التوليدي وتطبيقاته في نظم الوسائط المتعددة.

## الملفات الرئيسة

- `index.html`: الصفحة الرئيسية.
- `styles.css`: التنسيق العام والتجاوب.
- `script.js`: تأثير الظهور التدريجي للعناصر.
- `assets/`: الشعارات والوسائط النهائية.
- `report/report.html`: تقرير جاهز للطباعة إلى PDF.
- `report/student-info.txt`: أسماء وأرقام الطلاب.

## ملاحظات قبل التسليم

1. استبدل الملفات الوسائطية التجريبية بملفات نهائية بصيغ `WEBP` أو `AVIF` للصور.
2. أضف الفيديو النهائي مع الصوت والنصوص المتزامنة داخل قسم المحتوى الوسائطي.
3. افتح `report/report.html` ثم احفظه كملف `PDF`.
4. حدّث رابط الاستضافة المجانية داخل التقرير قبل الرفع النهائي.
